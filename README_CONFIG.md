# libVLRW 配置文件使用指南

## 快速开始

### 1. 配置文件位置

将 `config.ini` 放在可执行文件同目录：
```
build/bin/Release/
├── cornell_box_test.exe
├── config.ini          ← 这里
└── cornell_box.png
```

或者项目根目录（测试时会自动查找）。

### 2. 基础配置

```ini
[Render]
spp = 4              # 推荐: 4-16（更高=更少噪点但更慢）
maxDepth = 8         # 光线最大反弹次数
width = 512
height = 512

[Camera]
position = 0.0, 1.0, 0.6    # 相机在房间内
target = 0.0, 1.0, -0.5     # 看向蓝色后墙
up = 0.0, 1.0, 0.0
fov = 60.0                  # 视场角（度）

[Light]
position = 0.0, 1.8, 0.0    # 天花板中央（y=2.0 是天花板）
intensity = 20.0, 20.0, 20.0 # RGB 强度
```

### 3. 调整建议

#### 减少噪点
```ini
[Render]
spp = 16    # 或更高 (32, 64)
```

#### 更亮的场景
```ini
[Light]
intensity = 40.0, 40.0, 40.0  # 加倍强度
```

#### 测试多次反弹
```ini
[Render]
maxDepth = 16         # 增加反弹次数
spp = 8               # 需要更多采样以减少噪点

[Light]
position = 0.0, 0.5, 0.0   # 光源放低，制造更多间接光照
```

#### 不同视角
```ini
[Camera]
# 俯视图
position = 0.0, 1.9, 0.0
target = 0.0, 0.5, 0.0
fov = 90.0

# 或者侧视图
position = 0.8, 1.0, 0.0
target = -0.8, 1.0, 0.0
fov = 60.0
```

## 场景说明

当前测试场景（Closed Room RGB）:

```
        天花板 (灰色, y=2.0)
            ┌─────────────┐
            │   ● 光源    │  
   左墙     │  y=1.8      │  右墙
  (绿色)    │             │ (红色)
   x=-1     │  📦  📦     │  x=+1
            │ 物体1 物体2 │
            │             │
            │  👁 相机    │
            └─────────────┘
         地板 (灰色, y=0)
              
              后墙 (蓝色, z=-1)
```

- **房间尺寸**: x∈[-1,1], y∈[0,2], z∈[-1,1]
- **物体1**: 白色小盒子 @ (-0.3, 0, -0.3)
- **物体2**: 黄色小盒子 @ (0.3, 0, 0.3)
- **默认相机**: (0, 1, 0.6) 看向后墙

## 渲染效果预期

### spp=1 (默认，不推荐)
- 渲染时间: ~1秒
- 噪点: 极高
- 用途: 快速预览

### spp=4 (推荐用于测试)
- 渲染时间: ~4秒
- 噪点: 中等
- 用途: 开发调试

### spp=16 (推荐用于最终渲染)
- 渲染时间: ~16秒
- 噪点: 较低
- 用途: 质量检查

### spp=64 (高质量)
- 渲染时间: ~1分钟
- 噪点: 很低
- 用途: 最终输出

## 已知问题

### 1. 光线穿透（Light Leaking）
**现象**: 光线会穿过墙壁照亮不应该被照亮的区域。

**原因**: 当前版本未实现阴影光线追踪。

**临时解决**: 调整光源位置，避免直接照射墙壁背面。

### 2. 噪点
**现象**: 图像有颗粒感。

**解决**: 增加 `spp` 值。

### 3. 过暗或过亮
**解决**: 调整 `Light.intensity`。

## 故障排除

### 配置文件未加载
**症状**: 输出显示 "Warning: config.ini not found"

**解决**:
```bash
# 确认文件位置
dir build\bin\Release\config.ini

# 如果不存在，复制
copy config.ini build\bin\Release\
```

### 图像全黑
**检查**:
1. `Light.intensity` 是否太小？
2. `Light.position` 是否在房间外？（y 应在 0-2 之间）
3. `Camera.position` 是否在房间外？

### 渲染时间过长
**解决**:
1. 降低 `spp` (如 spp=2)
2. 降低分辨率 (如 256×256)
3. 减少 `maxDepth` (如 maxDepth=4)

## 性能优化建议

| 场景 | 推荐配置 |
|------|---------|
| 快速迭代 | spp=2, 256×256, maxDepth=4 |
| 开发测试 | spp=4, 512×512, maxDepth=8 |
| 质量检查 | spp=16, 512×512, maxDepth=8 |
| 最终渲染 | spp=64, 1024×1024, maxDepth=12 |
